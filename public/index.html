anotherexample.com

The permanent second domain for cross-origin, cookie, and integration testing.

example.com and example.org are reserved by IANA for documentation and can't be used for live testing. This domain fills that gap: a stable, real, second origin you can point to whenever a test needs two different domains — CORS checks, cookie isolation, redirect flows, iframe embedding.

Endpoints

GET/POST /api/echo

Returns your request back as JSON — method, headers, query params, body, and IP. Useful for inspecting exactly what a client sends.

GET/POST /api/cors

Responds with permissive CORS headers (Access-Control-Allow-Origin: *). Fetch it from any origin to confirm your cross-origin request handling works end-to-end.

GET /api/health

Simple health check — returns { status: "ok" }.

Quick example

fetch('https://anotherexample.com/api/cors')
  .then(r => r.json())
  .then(console.log);
